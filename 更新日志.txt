# ============================================================
#  v1.3 (2026-05-20)
# ============================================================

[修复] 主题切换后重启不生效的问题
       - 根因：settings.json 中保存的是中文显示名而非英文主题名
       - 修复：_on_apply_settings() 现在正确保存英文主题名

[新增] 主题预设系统（THEME_PRESETS）
       - 深色模式：深蓝黑背景 + 浅灰文字，真正的暗色界面
       - 护眼模式：米黄背景 + 深棕文字，减少蓝光刺激
       - 海洋蓝：  浅蓝背景 + 深蓝文字，清爽配色
       - 预设在运行时立即生效，无需重启

[新增] 设置页"高级操作"区
       - 恢复系统设置：重置字体/主题为默认值，不删除记账数据
       - 重置软件：删除所有数据（accounts.json + settings.json），两次确认

[新增] 分类频率排序
       - 记一笔时，分类下拉框按历史使用频率降序排列
       - "其他"始终排在最后

[新增] 分类扩充
       - 收入分类：6 → 8（新增 报销、租金）
       - 支出分类：8 → 12（新增 通讯、服饰、日用、社交）

[优化] 主题下拉框改为中文分组显示
       - 分组：主题预设 / 红色系 / 蓝绿色系 / 紫色系 / 暗色系 / 简约质感
       - 分隔行防误选

[文档] 新建 UI交互逻辑.txt
       - 从用户视角详解每个按钮的底层代码流
       - 列出完整函数代码 + 注释，适合学习 Python

[文档] 更新 阅读目录.txt
       - 同步行号和功能描述

       消耗 token：约 11,15 2,890

[新增] 设置持久化系统
       - settings.json 存储字体、主题、字号配置
       - load_settings() / save_settings() 原子读写

[新增] 设置页真正生效
       - 字体和字号：立即生效（更新 ttkbootstrap Style）
       - 主题：下次启动生效

[新增] DataTable 右键删除菜单
       - 右键表格行弹出"删除此记录"
       - delete_callback 参数启用/禁用

[新增] 缓冲保存模式
       - 增删操作只修改内存工作副本 self._entries
       - 关闭时弹出确认：保存 / 不保存 / 取消

[新增] 撤回删除功能
       - 删除的记录压入 _undo_stack（LIFO 栈）
       - "撤回删除"按钮一键恢复

[新增] 窗口关闭确认
       - WM_DELETE_WINDOW 拦截关闭事件
       - 三选一：保存并关闭 / 不保存直接关闭 / 取消返回

[重构] _refresh_list() 改为从内存工作副本读取
